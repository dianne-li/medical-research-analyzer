# Medical Research Analyzer

Medical Research Analyzer is a full-stack web application that uses AI to analyze biomedical research papers and generate concise, structured summaries. Users can upload a PDF and quickly view key information about the study, including its design, population, outcomes, findings, limitations, and clinical significance.

The application also provides supporting quotes from the original paper so users can verify the information generated by the AI.

## Features

- Upload and analyze biomedical research papers in PDF format
- Generate structured research summaries using Google Gemini
- Extract key information including:
  - Study design
  - Population and sample size
  - Intervention
  - Primary and secondary outcomes
  - Main findings
  - Clinical significance
  - Key statistics
  - Strengths and weaknesses
  - Limitations
- Display supporting quotes from the original paper
- Validate uploaded PDFs to ensure they are biomedical research papers
- Handle invalid or unsupported uploads with user-friendly error messages

## Tech Stack

**Frontend**
- React
- TypeScript
- Vite

**Backend**
- Python
- FastAPI
- Pydantic
- PyMuPDF

**AI**
- Google Gemini API

## How It Works

```text
PDF Upload
    ↓
Text Extraction
    ↓
Biomedical Paper Validation
    ↓
Gemini Analysis
    ↓
Structured Output
    ↓
Evidence Verification
    ↓
React Analysis Interface
```

The backend extracts text from the uploaded PDF using PyMuPDF. Gemini first determines whether the document is a biomedical research paper. If it is valid, Gemini generates a structured analysis that is validated using a Pydantic schema and returned to the frontend for display.

## Getting Started

### Clone the repository

```bash
git clone https://github.com/dianne-li/medical-research-analyzer.git
cd medical-research-analyzer
```

### Backend

Navigate to the backend:

```bash
cd backend
```

Create and activate a virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create a `.env` file inside the `backend` directory and add your Gemini API key:

```text
GEMINI_API_KEY=your_api_key
```

Start the backend:

```bash
uvicorn main:app --reload
```

The API will run at:

```text
http://127.0.0.1:8000
```

### Frontend

Open another terminal and navigate to the frontend:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown by Vite, typically:

```text
http://localhost:5173
```
